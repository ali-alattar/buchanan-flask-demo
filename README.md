# Flask API — Docker & Azure

Hi Buchanan Hiring team!!

This is a small learning project using fictional recruitment data.

I built this with Python, Flask and Gunicorn, packaged it with Docker, and deployed to Azure Container Apps using Azure Container Registry.

[Live API demo](https://buchanan-flask-demo.whitecoast-9e12cb6c.uksouth.azurecontainerapps.io/roles)

At the moment it just returns sample roles as JSON.

Thanks for taking a look!!
